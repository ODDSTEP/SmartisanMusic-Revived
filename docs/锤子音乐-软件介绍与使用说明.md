# 锤子音乐 · 软件介绍与使用说明

> 版本 1.4.24（versionCode 88）· 包名 `cn.chuizi.music` · 无网络权限、纯本地播放、不耗一点流量
> 这份说明覆盖当前版本**全部你能看得见、点得到**的功能。想了解某个功能是怎么一步步做出来的，看同目录《锤子音乐-完整更新日志》。

## 一、这是一台什么播放器

锤子音乐不是又一个"能放歌的 App"。它是一台把**发烧级音频链路**和**拟物唱盘交互**塞进手机的本地音乐播放器。

三个字概括：**真、全、稳**。

- **真**——音质不走套路。三套播放引擎按需自动切换，USB 独占做到采样率/位深"零损失"逐字节直传，不糊弄、不偷换。
- **全**——10 段 EQ、压限、混响、倒放、变速、智能交叉淡化、逐字歌词、打碟搓盘、唱盘爆豆音、18 套色彩主题……该有的全有，别家没有的也有。
- **稳**——每一版都对着几百条历史反馈逐条整改，把"代码写了但你看不到""改了一个坏三个""反复改不好"这类毛病一个个挖根除掉。

**它不联网**。整个 App 没有 INTERNET 权限，歌单、收藏、设置全在你手机本地。你不用担心隐私，也不用担心它偷跑流量。

## 二、安装与升级（先看这里）

- **覆盖安装即可**：从任意老版本直接覆盖安装，歌单 / 收藏 / 设置 / 播放记录一样不丢。**不用卸载、不用清数据**。
- **版本确认**：设置页显示 `1.4.24 / versionCode 88`。
- **同一签名**：历代版本同一个自签名证书，放心升级。
- **权限**：只有读本地音频文件的权限，没有网络权限。

## 三、三种播放引擎（设置 → 播放引擎）

一台播放器里装了三套真实链路，不是挂三个假标签。系统会根据你开的功能**自动选路**，也可以手动切。

| 引擎 | 定位 | 什么时候用它 |
|---|---|---|
| **系统直读**（系统解码） | 默认、音质党首选 | 原始音频直接交系统解码器，bit-perfect 位完美直出，功耗最低。常见格式 MP3/FLAC/WAV/AAC/OGG 默认走这条 |
| **BASS 流式解码**（主引擎） | 功能最全 | 开均衡器、压限、混响、倒放、变速、智能过渡、打碟时，自动走这条——所有音效都在这条链路上 |
| **ffmpeg 转码**（兜底） | 冷门格式专家 | APE、DSD（DFF/DSF）、DTS、WMA、TAK、WavPack、TTA 等系统解不了的格式，转成 FLAC 缓存后播放 |

**"引擎能力可见"**：设置里能看到当前这首歌实际走的是哪条路，心里有数。

## 四、音效与均衡器（设置 → 音效 / 均衡器）

| 功能 | 作用 | 怎么用 |
|---|---|---|
| **原声** | 不施加任何 EQ | 想听原始声音时选它 |
| **10 段 EQ / 预设音效** | 频点增益调节，多种预设（流行 / 摇滚 / 古典 / 爵士等） | 点选即生效，下方频响曲线实时变化 |
| **响度均衡（ReplayGain）** | 读响度标签统一音量，歌单不再忽大忽小 | 一个入口三件套：开关 + 标签增益 + 无标签回退 + 目标增益 -6~+6dB。旧版那两个重复入口已合并，全 App 只有这一处 |
| **压限器 + 强度** | 压大动态、防削波 | 音量开大或 EQ 增益高时开 |
| **音乐厅 / V3 混响** | 厅堂残响，两者可叠加 | 听感不同，按需搭配 |
| **声道平衡** | -100 全左 ~ +100 全右 | 单耳听音或声道不平衡时用 |
| **增益监测** | 音频面板显示峰值 / 余量 / RMS / 削波采样 | 想看有没有削波时开，削波采样 >0 就调低 EQ / 压限 |
| **倒放** | 反向播放 | 娱乐向 |
| **变速不变调** | 0.5x~2.0x，带抗锯齿 | 按需 |
| **淡入淡出** | 暂停 / 继续做音量渐变，防爆豆音 | 默认开 |

> 这些音效只施加一份（历史版本曾双份叠加产生刺耳噪声，已根治）。

## 五、智能过渡与打碟

- **智能过渡**：打开后切歌做淡入淡出交叉淡化，不再硬切。过渡时长点开是弹窗——3 / 6 / 10 秒点选，或自己输入 1~60 秒。
- **重要取舍**：按作者拍板，开过渡 = 全格式 PCM 混音（为了真的能淡入淡出），会暂时放弃 bit-perfect 直出；关掉就恢复纯直出。
- **打碟 / 搓盘**：播放页可以转唱片、搓碟，配唱针摩擦声、爆豆音、打碟音效。拖唱片定位进度松手后会自动接着播（不会再莫名自己停）。

## 六、音量控制

- **大播放页音量条**：左侧「−」右侧「+」，拖动调节，跟手机系统音量同步。
- **0 档真静音**：剩一格时按一次减键就到位，不用连按几十次（历史老大难，已根治）。
- **软件音量 ↔ 系统音量条平滑接力**：开相关开关后，App 音量与系统音量条做平滑接力，音频面板显示"目标 / 实际 / 读回一致"。
- **USB 独占下两种音量方式**（1.4.24 新增）：
  - **数字音量**：-60~0 dB 精确映射，配合 TPDF 抖动，衰减不丢精度。
  - **DAC 硬件音量**：直接调用 USB 声卡的硬件音量单元（UAC Feature Unit），写后回读验证；声卡不支持会自动退回数字音量。
  - 两种模式之间平滑交接，播放页有 dB 胶囊显示当前值。

- 播放 / 暂停、上下曲、随机、单曲 / 列表循环、进度拖动。
- **记忆式首页**：记住上次浏览位置。

- **通知栏控制**：媒体会话支持播放 / 暂停 / 上一曲 / 下一曲 / 收藏。1.4.24 通知栏做了整体返工：
  - **收起态更矮**，比普通通知还省地方；
  - **按钮放大到正常大小**，一眼看清、一按就中；

- **小播放栏 / 设置 / 歌曲信息长文字滚动**：文字太长会匀速滚动，慢慢转、帧率高、丝滑，不用省略号。

## 八、曲库、搜索与歌曲信息

- 本地扫描、隐藏文件（眼睛图标）、按音质 / 采样率 / 码率显示与排序。
- **逐字歌词**：内嵌 LRC 解析，大播放页逐字高亮。
- **封面**：内嵌封面 / 专辑图加载。
- **歌曲信息双数据源**：列表显示走系统索引；点"编辑歌曲信息"读文件内嵌标签，识别更准，保存后写回文件，列表跟着变对。
- **空专辑**：没有专辑信息的歌统一归入"未知专辑"，全部合并成一张；编辑清空专辑不会自动填充。
- **字母索引条**（按名称排序时左侧那一列）：按住上下拖就能连续跳字母；1.4.24 删掉了那个"一按就冒出来、挡住视线的大字母表浮层"，按住也不再整条发白看不清。

## 九、18 套色彩主题

默认"彩色"，另有 17 套主题，其中 9 套是严格按照 Material You（M3）规范固化下来的高级配色。每套主题在浅色 / 深色模式下都经过对比度校验，文字不会融进背景里。

- 色彩主题列表右侧的色点，用的是能代表该主题的颜色，一眼对得上。
- 选了 M3 类主题时，三个莫奈取色开关会置灰——因为 M3 主题本身就是一套完整取色方案，再开莫奈没有意义，置灰是防止你糊涂。

## 十、USB 独占（发烧友重点）

插上 USB 小尾巴（DAC）：

- **真 USB Host 独占**：UAC 直出，系统音量不参与，采样率 / 位深不被偷偷改。
- **零损失（bit-perfect）**：源是什么位深就按什么位深送，逐字节直传，不改一个字节。
- **音频面板**显示设备真实采样率 / 位深 / 通道。
- **不播放 DSD 开关**：开了之后 DSD / DSF / DFF 不入队不播。
- **关独占后麦克风恢复**：关掉独占，耳机麦克风立刻还给系统。

> USB 独占与具体硬件强相关，建议在真机（带 USB DAC）上逐条确认；反馈问题时附上完整日志即可。

## 十一、唱盘爆豆音（1.4.24 精调）

播放页打碟 / 唱盘效果里的"爆豆音"，模拟真实黑胶唱盘被唱针读到时的细微杂音。1.4.24 按真实环境重新标定了触发频率：

- 采样都是**单次爆豆**（约 0.15~0.25 秒），不是一长段连响；
- 频率按三种成因做了疏密区分——**灰尘掉落**最偶发、**轻微磨损**居中、**轻微划痕**稍密；
- 整体按"轻微磨损唱盘"标定，比上一版明显稀疏（大概每 3~6 秒一次），听感是安静唱盘上的偶发细响，不是密集噼啪。

## 十二、日志与排障（你反馈问题时的正确姿势）

- **AppLog 日志导出**：设置里能导出完整日志快照，带会话头、版本号、排障字段，信息量很足。
- **反馈问题时**：描述"我做了什么 → 期望怎样 → 实际怎样"就够了，然后**把日志压缩包整个发回来**，不用你自己去翻、也不用费心找关键字、更不用精确到几分几秒——这些我们来查。

## 十三、诚实的边界

- 听感、闪退稳定性、USB 独占、DSD/APE 兼容、过渡顺滑度这些，开发环境不具备真机，音频与设备相关行为需在真机上确认；代码编译通过不等同于真机验证通过。
- 少数历史欠账项（音量段数翻倍、部分极细节 UI）仍在《全量需求清单》里标注"欠账·记着"，没有假装完成。
- 频响预览是近似曲线，与真实滤波器有细微差别，属正常。
